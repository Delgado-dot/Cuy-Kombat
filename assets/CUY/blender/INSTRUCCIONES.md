# Personajes en Blender

1. Abre Blender y selecciona la pestaña **Scripting**.
2. En el editor de texto, pulsa **Open** y abre `personajes_escena.py`.
3. Pulsa **Run Script**.
4. Espera a que se creen los seis personajes.
5. Pulsa **F12** para renderizar la escena.

El archivo genera cuatro cobayas y dos conejos mediante primitivas editables. Incluye el poncho andino, las grietas luminosas, materiales, poses, suelo, luces y cámara. Guarda el archivo `.blend` después de ejecutar el script para conservar la escena.
